📋 개요

시작 전 확인사항

이 문서는 개발 경험이 없는 팀원이 Claude Code CLI를 활용한 AI 개발환경을 처음부터 셋업할 수 있도록 작성되었습니다.

✅ 필요한 준비물

📧 개인 이메일 주소 (GitHub 가입용)
🔑 Claude 계정 정보 (팀 관리자에게 별도 전달)
🌐 안정적인 인터넷 연결
💻 macOS 또는 Windows 10/11 PC
💡 이 문서를 순서대로 따라하면 약 30~60분 내에 셋업이 완료됩니다. Claude 계정은 회사에서 제공합니다.
PART 1

GitHub 계정 만들기

GitHub는 코드를 저장·공유하는 플랫폼입니다. macOS/Windows 공통으로 진행합니다.

1
GitHub 사이트 접속
웹 브라우저에서 github.com 에 접속합니다.
2
회원가입 시작
Sign up 버튼 클릭 → 이메일 입력 → 비밀번호 설정 → 사용자명(username) 입력
3
이메일 인증
가입한 이메일로 발송된 인증 코드(6자리)를 입력합니다.
4
플랜 선택
Free 플랜 선택 (비용 없음) → 설문은 스킵 가능
5
가입 완료 확인
대시보드 화면이 보이면 GitHub 계정 생성 완료!
⚠️ 사용자명(username)은 나중에 바꾸기 어렵습니다. 영문 소문자와 숫자, 하이픈(-)만 사용하세요.
예: imfine-gildong
PART 2

macOS 환경 셋업

Apple Silicon(M1/M2/M3) 및 Intel Mac 모두 지원합니다. Windows 사용자는 PART 3으로 이동하세요.

🍎 macOS 전용 섹션

2-1. Homebrew 설치 (패키지 관리자)

Homebrew는 macOS에서 개발 도구를 쉽게 설치할 수 있게 해주는 필수 도구입니다.

① Terminal 앱 실행

  • Spotlight 검색 (Cmd + Space) → Terminal 입력 → Enter

② 아래 명령어를 터미널에 붙여넣고 Enter

bash 
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
⚠️ Mac 로그인 비밀번호를 요청하면 입력하세요. 입력 시 화면에 아무것도 표시되지 않는 것이 정상입니다.

③ 설치 완료 후 PATH 추가 — 터미널에 표시되는 'Next steps' 명령어를 실행합니다:

bash 
echo 'export PATH="/opt/homebrew/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

④ 설치 확인

bash 
brew --version
# Homebrew 4.x.x 와 같은 버전 번호가 출력되면 성공!

2-2. Node.js 설치

Node.js는 Claude Code 실행에 필요한 런타임 환경입니다.

bash 
brew install node

설치 확인:

bash 
node --version    # v18 이상이면 OK
npm --version     # v8 이상이면 OK

2-3. Git 개인정보 설정

Git은 macOS에 기본 설치되어 있습니다. 개인정보만 설정하면 됩니다.

bash 
git config --global user.name "홍길동"
git config --global user.email "your@email.com"
# GitHub 가입 시 사용한 이름과 이메일을 입력하세요

2-4. VS Code 설치

bash 
brew install --cask visual-studio-code

설치 후 VS Code를 실행하고 Cmd+Shift+P → "Shell Command: Install code command in PATH" 선택

💡 또는 code.visualstudio.com 에서 직접 다운로드 후 Applications 폴더로 드래그해도 됩니다.

2-5. Claude Code CLI 설치 및 로그인

bash 
npm install -g @anthropic-ai/claude-code

설치 확인:

bash 
claude --version

Claude Code 실행 및 로그인:

bash 
claude
# 처음 실행 시 로그인 화면이 나타납니다
🔑 회사 제공 계정 정보
아래 정보를 입력하세요 (팀 관리자에게 전달받은 내용):

  • 이메일:             ___________________________
  • 비밀번호:          ___________________________
  • API 키 (선택):  ___________________________
💡 'claude: command not found' 오류가 나면 터미널을 완전히 닫고 다시 열어 재시도하세요.

🪟 Windows 전용 섹션

3-1. Windows Terminal 설치 (권장)

기본 cmd보다 훨씬 편리한 터미널입니다.

1
Microsoft Store 실행
시작 메뉴에서 Microsoft Store 검색 후 실행

'Windows Terminal' 검색 후 설치
설치 후 시작 메뉴에서 Windows Terminal 실행

3-2. Node.js 설치

1
nodejs.org 접속
LTS(Long Term Support) 버전 다운로드 클릭
2

설치 마법사에서 모두 다음(Next) 클릭 (기본 설정 유지)
3
설치 확인
Windows Terminal 열고 아래 명령어 실행
powershell 
node --version    # v18 이상이면 OK
npm --version     # v8 이상이면 OK

3-3. Git 설치 및 설정

1
git-scm.com 접속
Download for Windows 클릭 → .exe 파일 실행
2
설치 진행
모든 옵션 기본값 유지로 설치 완료
3
개인정보 설정
Windows Terminal에서 아래 명령어 실행
powershell 
git config --global user.name "홍길동"

3-4. VS Code 설치

1

2

3
설치 완료 후 Terminal 재시작
Windows Terminal을 완전히 닫고 다시 열기

설치 확인:

powershell

PART 4

GitHub 연동

macOS/Windows 공통으로 진행합니다. GitHub CLI를 설치하고 로그인합니다.

🍎 macOS
bash 
brew install gh
🪟 Windows
powershell 
winget install GitHub.cli
# winget 사용 불가 시 → cli.github.com 에서 수동 다운로드

GitHub 로그인 (공통)

bash / powershell 
gh auth login
1
GitHub.com 선택 → Enter
2
HTTPS 선택 → Enter
3
Login with a web browser 선택 → Enter
4
화면에 표시된 코드를 복사 → 자동으로 열리는 브라우저에 코드 붙여넣기
5
GitHub 계정으로 인증 완료

연동 확인:

bash / powershell 
gh auth status
✅ "Logged in to github.com as [사용자명]" 메시지가 보이면 연동 성공!
PART 5

Claude Code 첫 사용 가이드

Claude Code를 실행하고 첫 번째 대화를 시작해봅니다.

프로젝트 폴더 만들기

🍎 macOS
bash 
mkdir ~/projects/my-project
cd ~/projects/my-project
claude
🪟 Windows
powershell 
mkdir C:\projects\my-project
cd C:\projects\my-project
claude

기본 명령어

명령어 / 단축키 기능
/help도움말 표시
/exit 또는 /quitClaude Code 종료
Ctrl+C (Windows) / Cmd+C (Mac)현재 작업 중단
/clear대화 기록 초기화

활용 예시 프롬프트

  • "간단한 HTML 페이지를 만들어줘"
  • "이 코드를 한국어로 설명해줘"
  • "Python으로 엑셀 파일 읽는 코드 작성해줘"
  • "이 오류를 수정해줘: [오류 메시지 붙여넣기]"
  • "이 폴더 구조로 프로젝트를 초기화해줘"
🔧 트러블슈팅

자주 발생하는 문제 해결

문제가 생겼을 때 가장 먼저 시도해볼 것들입니다.

command not found 오류가 납니다
  • 터미널/Windows Terminal을 완전히 닫고 다시 열어서 재시도
  • macOS: source ~/.zshrc 실행 후 재시도
  • Windows: 시스템 재시작 후 재시도
npm 권한 오류가 납니다 (macOS)
sudo chown -R $(whoami) /usr/local/lib/node_modules
Windows PowerShell에서 스크립트 실행이 차단됩니다
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
GitHub 인증 오류가 납니다
gh auth logout
gh auth login
# 로그아웃 후 다시 로그인
Claude API 키 관련 오류가 납니다
console.anthropic.com 접속 → API Keys 메뉴 → 새 키 발급 후 다시 시도. 또는 팀 관리자에게 계정 정보 재전달을 요청하세요.
